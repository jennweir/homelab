# CoreOS Kubernetes Playbook

This playbook prepares Fedora CoreOS x86_64 nodes for a Kubernetes cluster using CRI-O.

## Prerequisites

Build the custom FCOS image and OCI archive first:

```bash
../../coreos-lab/create-fcos-k8s-iso.sh
```

The script creates the dated SSH key and generates:

```text
inventory
```

Edit that inventory with the IP addresses for the CoreOS nodes. The inventory references the private key generated by the ISO script.

## Run

From this directory:

```bash
ansible-playbook -i inventory install-k8s.yaml
```

The playbook:

- Disables swap.
- Loads Kubernetes kernel modules and sysctls.
- Copies the custom FCOS OCI archive to each node.
- Performs the persistent `rpm-ostree` rebase.
- Reboots nodes one at a time.
- Starts CRI-O and enables kubelet.
- Verifies the Kubernetes binaries and CRI-O socket.

Run `kubeadm init` manually on the first control-plane node, then run `kubeadm join` on the remaining nodes.

## Inventory template

Use `inventory.example` as the starting point when the generated inventory is not available.
